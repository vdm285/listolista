📡 ListoLista (v1.3): The Static Sovereign"Perfection is achieved, not when there is nothing more to add, but when there is nothing left to take away." — Antoine de Saint-ExupéryListoLista is a "Soul Prototype" of a collaborative To-Do list. It challenges the modern web stack by delivering Google Docs-style real-time collaboration without a single database, server, or login account.It runs entirely on GitHub Pages (Static HTML) and utilizes the global BitTorrent Network to connect users.⚡️ The "Magic" (How it Works)Most collaborative apps need a central server to pass messages. ListoLista refuses to use one.Instead, it uses a technique called The Torrential Mesh:The Room: When you create a list, the URL generates a unique "Room ID" in the hash (e.g., #list-8f92a).The Signal: Your browser connects to public BitTorrent Trackers (the same ones used for file sharing). It announces: "I am in room #list-8f92a".The Connection: The tracker introduces you to anyone else in that room. Your browsers form a direct, encrypted WebRTC pipe.The Sync: Updates flow directly from Peer-to-Peer. The server never sees your data.🚀 Usage Guide1. Create & ShareOpen the app.Copy the URL (which now includes your unique Room Hash).Send it to a friend.Magic: When they open it, you will see a "👋" notification. Type, and they see it instantly.2. Save & KeepAuto-Save: Data is saved to your device's localStorage instantly.File Export: Click 💾 to download a JSON backup. This is your "Digital Paper."File Import: Click 📂 to restore a backup.⚠️ "Devil's Advocate" (Risks & Trade-offs)In the spirit of "Anti-Slop" engineering, we must be honest about the limitations of a Serverless P2P architecture:The "Ghost Data" Reality: Since there is no central database, at least one person must be online to "seed" the list. If everyone closes the tab, the "Room" is empty. The data lives in your browser, not in the cloud.Conflict Resolution: V1 uses a "Last-Write-Wins" strategy. If two users edit the exact same letter at the exact same millisecond, one will overwrite the other.Privacy Metadata: While your list content is encrypted between peers, the fact that you are connecting to a specific Room ID is visible to the public BitTorrent trackers.🛠 Technical StackCore: Vanilla HTML5 / ES6 JavaScript.Network: trystero (7kB) for abstracting WebRTC & Torrent signaling.Persistence: localStorage.Styling: Native CSS Variables (Pragmatic Utility).Codebase StructureThe entire application logic resides in a single file: index.html. This ensures the app is portable, auditable, and works offline (once loaded).🤖 AI CollaborationBuilt via a Human-in-the-Loop workflow with Google Gemini.Architect: Human Operator.Vibe Coder: Gemini.Consultants: A "Council of AIs" (Claude, GPT-4, DeepSeek) was convened to solve the "Static Sovereign" paradox, resulting in the Trystero implementation.
